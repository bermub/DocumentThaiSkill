# Thai Document Word-Wrap (ตัดคำไทยให้สวยงาม)

## ปัญหาที่ skill นี้แก้

ภาษาไทยเขียนติดกันไม่เว้นวรรคระหว่างคำ โปรแกรมจัดหน้า (เบราว์เซอร์ Word ตัวสร้าง PDF) จึงไม่รู้ว่าคำจบตรงไหน เมื่อข้อความยาวเกินบรรทัดมันจะ **ตัดกลางคำ** เช่น "การออกแบบเครือ‑\nข่าย" ทำให้อ่านยากและดูไม่เป็นมืออาชีพ

วิธีแก้: ใช้พจนานุกรมตัดคำ (PyThaiNLP) หาขอบเขตคำ แล้วแทรกอักขระ **Zero-Width Space (U+200B)** ที่ขอบเขตคำ อักขระนี้มองไม่เห็นและไม่กินที่ แต่บอกโปรแกรมว่า "ตัดบรรทัดตรงนี้ได้" ผลคือบรรทัดจะตัดที่ **ท้ายคำเสมอ**

## เมื่อไรควรใช้

ใช้เมื่อผู้ใช้:
- บ่นว่าเอกสารไทย "ตัดบรรทัดกลางคำ" / "ขึ้นบรรทัดใหม่ไม่สวย" / "คำขาด"
- ขอให้ "ตัดคำ" "จัดคำ" หรือทำ word wrap ภาษาไทย
- สร้างหรือจัดรูปแบบรายงาน ใบความรู้ ข้อสอบ จดหมาย เอกสารราชการ เป็นภาษาไทย (โดยเฉพาะ HTML/PDF ที่ต้องจัดขอบชิดสองข้าง)
- ทำเอกสาร .docx/.html ภาษาไทยที่ต้องดูเรียบร้อยเป็นทางการ

แม้ผู้ใช้ไม่พูดคำว่า "ตัดคำ" ตรง ๆ แต่ถ้ากำลังจัดหน้าเอกสารไทยให้สวยงาม ให้พิจารณาใช้ skill นี้

## เริ่มใช้เร็ว (Quick Start)

สคริปต์หลักอยู่ที่ `scripts/thai_wrap.py` ตรวจรูปแบบไฟล์อัตโนมัติจากนามสกุล

```bash
# ติดตั้ง dependency (ถ้ายังไม่มี)
pip install pythainlp --break-system-packages -q          # จำเป็นเสมอ
# beautifulsoup4 (HTML) และ python-docx (DOCX) มักมีอยู่แล้ว ถ้าไม่มีให้ติดตั้งเพิ่ม

# ข้อความ → stdout
echo "การออกแบบและการจัดการเครือข่ายในองค์กร" | python3 scripts/thai_wrap.py

# ไฟล์ Word: ได้ไฟล์ใหม่ที่ลงท้าย .wrapped.docx
python3 scripts/thai_wrap.py report.docx -o report_final.docx

# ไฟล์ HTML
python3 scripts/thai_wrap.py page.html -o page_wrapped.html

# ไฟล์ข้อความ
python3 scripts/thai_wrap.py notes.txt -o notes_wrapped.txt
```

## สามโหมดการทำงาน

| รูปแบบไฟล์ | สิ่งที่ทำ | หมายเหตุ |
|---|---|---|
| **.txt / stdin** | แทรก ZWSP ทุกขอบเขตคำ รักษาการขึ้นบรรทัดเดิม | เหมาะกับข้อความดิบ |
| **.html / .htm** | แทรกเฉพาะใน text node ไม่แตะ tag/attribute ข้าม `<script> <style> <pre> <code>` | เลือก `--marker wbr` เพื่อใช้แท็ก `<wbr>` แทน ZWSP ได้ (ZWSP เป็นค่าเริ่มต้นเพราะใช้กับ PDF ได้ด้วย) |
| **.docx** | แทรก ZWSP ในทุก run รวมหัวข้อ ตาราง หัว/ท้ายกระดาษ และตั้งภาษา complex-script เป็น `th-TH` | ต้องระบุ `-o` หรือจะได้ไฟล์ `*.wrapped.docx` |

ออปชันเพิ่มเติม:
- `--engine newmm|longest|nlpo3` — เอนจินตัดคำ (ค่าเริ่มต้น `newmm` เร็วและแม่นพอใช้)
- `--no-lang` — DOCX: ไม่ต้องไปตั้งค่าภาษา
- `--format text|html|docx` — บังคับรูปแบบ (กรณีนามสกุลไม่ตรง)

## ทำเอกสาร HTML/พิมพ์ให้สวยงาม

การแทรก ZWSP อย่างเดียวยังไม่พอ ต้องมี CSS บอกเบราว์เซอร์ให้ตัดบรรทัดเฉพาะที่จุดตัด และจัดขอบเรียบ ใช้แม่แบบ `assets/thai-print.css` หรืออย่างน้อยใส่กฎสำคัญนี้:

```css
body { font-family: "TH Sarabun New", "TH SarabunPSK", sans-serif; line-height: 1.5; }
p {
  text-align: justify;          /* ขอบชิดสองข้าง ดูเป็นทางการ */
  word-break: normal;           /* อย่าตัดกลางคำเอง */
  overflow-wrap: break-word;    /* กันคำยาว/URL ล้นขอบ */
  hyphens: none;                /* ไทยไม่ใช้ยัติภังค์ */
}
```

และตั้ง `<html lang="th">` เสมอ จุด ZWSP กับ `text-align: justify` ทำงานร่วมกัน เบราว์เซอร์จะกระจายช่องว่างที่ขอบเขตคำพอดี ทำให้ขอบขวาเรียบโดยไม่ตัดกลางคำ ดูแม่แบบเต็ม (รวม `@page`, `@media print`, การกันหัวข้อโดดเดี่ยว) ใน `assets/thai-print.css`

## ทำเอกสาร Word (.docx) ให้สวยงาม

1. สร้าง/จัดเนื้อหา .docx ตามปกติ (ใช้ **docx skill** ที่ `/mnt/skills/public/docx/SKILL.md` สำหรับฟอนต์ ขอบ ระยะ)
2. **ตั้ง alignment เป็น LEFT** สำหรับ body text ภาษาไทยทุกย่อหน้า (ดูหมายเหตุด้านล่าง)
3. รันสคริปต์นี้ทับไฟล์ผลลัพธ์เป็นขั้นสุดท้าย เพื่อแทรกจุดตัดคำ:
   ```bash
   python3 scripts/thai_wrap.py output.docx -o output_final.docx
   ```

Word มีตัวตัดคำไทยในตัวอยู่แล้วเมื่อภาษาของข้อความตั้งเป็นไทย สคริปต์จึงตั้ง `th-TH` ให้ด้วย และเพิ่ม ZWSP เป็นจุดตัดที่ชัดเจน ทำให้ผลแน่นอนข้ามเครื่อง/เวอร์ชัน **ควรรันเป็นขั้นตอนสุดท้าย** หลังแก้เนื้อหาเสร็จแล้ว

> **⚠️ LEFT vs JUSTIFY ใน .docx**
>
> | Alignment | พฤติกรรมใน Word | แนะนำ |
> |---|---|---|
> | **LEFT** + ZWSP | ตัดที่ขอบเขตคำพอดี ขอบขวาหยัก แต่อ่านง่าย | ✅ .docx ภาษาไทย |
> | **JUSTIFY** + ZWSP | Word กระจาย space ที่ทุก ZWSP → ช่องว่างถ่างผิดปกติ | ❌ |
> | **JUSTIFY** (ไม่มี ZWSP) | Word ไม่รู้จุดตัดคำ กระจาย space inter-word → ถ่างเช่นกัน | ❌ |
> | **JUSTIFY** + CSS `inter-character` | กระจาย space ระหว่างอักขระ ดูสวยงาม | ✅ HTML/PDF เท่านั้น |
>
> **สรุป: ใช้ LEFT สำหรับ .docx, ใช้ JUSTIFY สำหรับ HTML/PDF เท่านั้น**

## มาตรฐานการย่อหน้า (first-line indent) สากลตามงานวิจัย

"การแท๊ปหน้าเอกสาร" = การย่อหน้าบรรทัดแรกของแต่ละย่อหน้า มาตรฐานสากลของงานวิจัย (APA 7th / MLA 9th / Chicago) กำหนดไว้ที่ **1.27 ซม. (0.5 นิ้ว = 720 DXA)** ซึ่งตรงกับระยะแท็บเริ่มต้นของ Word พอดี ใช้ `scripts/apply_indent.py` ตั้งค่าให้อัตโนมัติ:

```bash
python3 scripts/apply_indent.py research.docx -o research_final.docx        # 1.27 ซม. (สากล)
python3 scripts/apply_indent.py thesis.docx --cm 1.0 -o thesis_final.docx    # 1.0 ซม. (วิทยานิพนธ์ มจพ.)
```

สคริปต์ตั้ง first-line indent ให้เฉพาะ **ย่อหน้าเนื้อความ** และตั้ง `defaultTabStop = 720` ให้ด้วย โดย **ข้ามอัตโนมัติ**: หัวข้อ (Heading/Title), คำบรรยายภาพ/ตาราง, ข้อความจัดกึ่งกลาง/ชิดขวา และเซลล์ตาราง (ใช้ `--tables` ถ้าต้องการย่อในตารางด้วย)

> หลักสำคัญ: อย่าย่อหน้าด้วยการกด Tab จริงหรือเคาะเว้นวรรค ให้ตั้งค่าที่ระดับย่อหน้า เพื่อให้ระยะคงที่และแก้ทั้งเอกสารได้ — รายละเอียดและตารางเทียบมาตรฐานดูใน `references/research-indent-standard.md`

## กั้นหน้าหลัง (Page Margins) — `page_margin.py`

ตั้งขอบกระดาษให้ทุก section ใน .docx รองรับ preset สำเร็จรูปและกำหนดเองได้

```bash
# preset สำเร็จรูป
python3 scripts/page_margin.py report.docx --preset a4-thai -o report_final.docx
python3 scripts/page_margin.py thesis.docx --preset thesis-mku -o thesis_final.docx

# กำหนดเองเป็นซม.
python3 scripts/page_margin.py input.docx --top 3 --bottom 2.5 --left 3 --right 2.5 -o out.docx
```

| Preset | บน | ล่าง | ซ้าย | ขวา | เหมาะกับ |
|---|---|---|---|---|---|
| `a4-thai` | 2.54 | 2.54 | 3.0 | 2.0 | เอกสารราชการไทย |
| `a4-standard` | 2.54 | 2.54 | 2.54 | 2.54 | เอกสารทั่วไป (1" ทุกด้าน) |
| `thesis-mku` | 3.0 | 2.5 | 4.0 | 2.5 | วิทยานิพนธ์ มจพ. (คู่มือ 2558) |
| `report` | 2.5 | 2.5 | 3.0 | 2.5 | รายงานทั่วไป |

สำหรับ HTML/PDF ให้แก้ `@page { margin: ... }` ใน `assets/thai-print.css` โดยตรง (มี preset ให้เปลี่ยนแปลงในคอมเมนต์)

## ป้องกันตารางล้นขอบ (Table Overflow) — `table_fit.py`

ตารางที่ copy-paste จาก Excel หรือกำหนดความกว้างแบบ fixed มักล้นออกนอกกระดาษ script นี้ตรวจและแก้อัตโนมัติ

```bash
# auto: ย่อเฉพาะตารางที่ล้น (ค่าเริ่มต้น แนะนำ)
python3 scripts/table_fit.py input.docx -o output.docx

# autofit: ทุกตารางใช้ AutoFit to Window
python3 scripts/table_fit.py input.docx --mode autofit -o output.docx

# fixed: ย่อสัดส่วนทุกตารางโดยไม่ AutoFit
python3 scripts/table_fit.py input.docx --mode fixed -o output.docx
```

| Mode | พฤติกรรม | เหมาะกับ |
|---|---|---|
| `auto` | ย่อเฉพาะตารางที่กว้างกว่าพื้นที่ข้อความ | ใช้ทั่วไป (ค่าเริ่มต้น) |
| `autofit` | ตั้ง AutoFit to Window ทุกตาราง | ต้องการให้ตารางยืดหยุ่น |
| `fixed` | ย่อสัดส่วนคอลัมน์ทุกตาราง ไม่ AutoFit | ต้องการควบคุมความกว้างแน่นอน |
| `pct` | ตั้ง 100% ของพื้นที่ข้อความทุกตาราง | เอกสารที่มีหลายคอลัมน์ |

สำหรับ HTML ให้ใช้กฎ CSS จาก `assets/thai-print.css` (บล็อก `.table-wrap` และ `table`) ที่เพิ่มไว้แล้ว เพียงห่อตารางด้วย `<div class="table-wrap"><table>...</table></div>`

## ลำดับการทำงานในงานวิจัย (แนะนำ)

1. สร้าง/แก้เนื้อหา .docx (ใช้ docx skill)
2. `page_margin.py` — ตั้งขอบกระดาษให้ถูกต้องตามมาตรฐาน
3. `table_fit.py` — ป้องกันตารางล้นขอบ

## หลักการทำงาน (สำหรับปรับแต่ง)

- **ZWSP (U+200B)** = จุดที่ "ตัดบรรทัดได้" มองไม่เห็น ไม่กินที่ ใช้ได้ทั้ง HTML, Word, PDF
- **`<wbr>`** = แท็ก HTML ที่ให้ผลเดียวกัน แต่เห็นใน source (เลือกด้วย `--marker wbr`) ไม่ติดไป PDF บางตัว
- สคริปต์ **ไม่แทรกก่อน** อักขระที่ห้ามขึ้นต้นบรรทัด (ๆ ฯ) และ **ไม่แทรกติดช่องว่าง**
- ทำงานแบบ **idempotent**: รันซ้ำได้ ไม่สะสมอักขระ (ลบ ZWSP เดิมก่อนเสมอ) และลบ ZWSP ออกแล้วได้ข้อความต้นฉบับกลับมาทุกตัวอักษร

## ข้อควรระวัง

- ZWSP อาจติดไปเวลา **คัดลอกข้อความ** ออกจากเอกสาร โดยปกติไม่กระทบการอ่าน แต่ถ้าจะนำข้อความไปประมวลผลต่อ (เช่น ค้นหา) ให้ลบ U+200B ออกก่อน: `text.replace('\u200b','')`
- การตัดคำด้วยพจนานุกรมไม่แม่น 100% คำเฉพาะ/ศัพท์ใหม่อาจตัดพลาดบ้าง ปรับ `--engine` หรือเพิ่มคำใน custom dictionary ของ PyThaiNLP ได้
- อย่ารันบนไฟล์ที่ไม่ใช่ภาษาไทยล้วน — สคริปต์ข้ามช่องว่างและไม่ยุ่งกับอังกฤษ/ตัวเลข แต่ไม่จำเป็นต้องใช้กับเอกสารที่ไม่มีไทย
