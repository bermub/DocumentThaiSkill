# มาตรฐานการย่อหน้า (First-Line Indent) และระยะแท็บ — สากลตามงานวิจัย

"การแท๊ปหน้าเอกสาร" คือการย่อหน้าบรรทัดแรกของแต่ละย่อหน้า (first-line indent)
ซึ่งเดิมมักทำด้วยการกดปุ่ม Tab งานวิจัย/วิชาการสากลกำหนดระยะนี้ไว้ชัดเจน

## ค่ามาตรฐานที่ใช้

| รูปแบบ | ย่อหน้าบรรทัดแรก | นิ้ว | DXA (twips) |
|---|---|---|---|
| **สากล (APA 7th, MLA 9th, Chicago, Turabian)** | **1.27 ซม.** | **0.5"** | **720** |
| วิทยานิพนธ์ มจพ. (KMUTNB) | 1.0 ซม. | 0.39" | 567 |
| ระยะแท็บเริ่มต้นของ Word | 1.27 ซม. | 0.5" | 720 |

**ค่าเริ่มต้นของ skill = 1.27 ซม. (720 DXA)** ตรงกับมาตรฐานสากลและระยะแท็บปกติของ Word
พอดี ดังนั้นการกด Tab 1 ครั้งจะได้ระยะย่อหน้าเท่ามาตรฐานทันที

## หลักการสำคัญ (สากล)

- ย่อหน้า **ทุกย่อหน้าเนื้อความ** ด้วยระยะเท่ากัน (รวมย่อหน้าแรกของหัวข้อ ในรูปแบบสากลทั่วไป)
- **ไม่** ย่อหน้า: หัวข้อ (heading), ชื่อเรื่อง, คำบรรยายภาพ/ตาราง (caption), ข้อความจัดกึ่งกลาง
- **ไม่** ใส่ย่อหน้าด้วยการเคาะเว้นวรรคหรือกด Tab จริง แต่ตั้งค่า first-line indent ที่ระดับย่อหน้า
  เพื่อให้ระยะคงที่และแก้ไขได้ทั้งเอกสาร (กด Tab จริงจะหลุดมาตรฐานเมื่อแก้ข้อความ)
- บล็อกอ้างอิงยาว (block quote) เยื้องทั้งย่อหน้าเท่าระดับย่อหน้า ไม่ใช้ first-line indent

## การนำไปใช้

### DOCX
```bash
python3 scripts/apply_indent.py research.docx -o research_final.docx        # 1.27 ซม. (สากล)
python3 scripts/apply_indent.py thesis.docx --cm 1.0 -o thesis_final.docx   # 1.0 ซม. (มจพ.)
```
สคริปต์ตั้ง `w:defaultTabStop = 720` ให้ด้วย และข้ามหัวข้อ/ข้อความกึ่งกลาง/เซลล์ตารางอัตโนมัติ

### docx-js (ตอนสร้างเอกสาร)
```javascript
// ระดับย่อหน้าเนื้อความ
new Paragraph({ alignment: AlignmentType.JUSTIFIED,
  indent: { firstLine: 720 },   // 720 DXA = 1.27 ซม. = 0.5"
  children: [run(text)] });

// ตั้งระยะแท็บเริ่มต้นทั้งเอกสารใน section properties
// <w:defaultTabStop w:val="720"/>  (มาตรฐานสากล)
```

### HTML / พิมพ์
```css
p { text-indent: 1.27cm; }   /* ย่อหน้าบรรทัดแรก สากล */
```
ดูแม่แบบเต็มใน `assets/thai-print.css`

## ลำดับขั้นแนะนำในงานวิจัย

1. สร้าง/แก้เนื้อหา .docx (ใช้ docx skill)
2. `apply_indent.py` — ตั้งย่อหน้าสากล 1.27 ซม.
3. `thai_wrap.py` — ตัดคำไทยกันบรรทัดตัดกลางคำ (ทำขั้นสุดท้าย)
